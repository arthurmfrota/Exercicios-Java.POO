# ☕ Exercícios de Programação Orientada a Objetos — Java

Repositório criado para armazenar exercícios e atividades acadêmicas desenvolvidos durante os estudos de **Programação Orientada a Objetos (POO) em Java**.

## 📚 Conteúdos praticados

* Classes e objetos
* Atributos e métodos
* Construtores
* Encapsulamento
* Modificadores de acesso (`private` e `public`)
* Getters e setters
* Métodos com parâmetros e retorno
* Sobrescrita do método `toString()`
* Validação de dados
* Organização de classes em Java

## 📝 Exercícios

### 📖 Livro

Classe desenvolvida para representar um livro, trabalhando com:

* Título
* Autor
* Ano de publicação
* Preço
* Construtor
* Getters e setter
* Cálculo da idade do livro
* Método `toString()`

### 👤 Pessoa

Exercício para praticar criação de objetos, atributos, métodos e encapsulamento.

### 📐 Retângulo

Exercício envolvendo:

* Largura
* Altura
* Cálculo da área
* Cálculo do perímetro
* Construtor

### 💰 Conta

Exercício para praticar atributos privados, getters, métodos e regras de negócio.

### 👨‍💼 Funcionário

Exercício envolvendo atributos, encapsulamento e método para aumento salarial.

### 🎓 Turma

Exercício envolvendo vetores, objetos e métodos para análise dos alunos.

## 🛠️ Tecnologias

* Java
* Programação Orientada a Objetos
* Visual Studio Code
* Git
* GitHub

## 🎯 Objetivo

Praticar os fundamentos da Programação Orientada a Objetos e desenvolver uma base sólida em Java, aplicando os conceitos estudados em exercícios práticos.
